# Contributing

Focused issues and pull requests are welcome.

1. Install `python -m pip install -e ".[analysis,assets,dev]"`.
2. Add or update tests for behavioral changes.
3. Run `python -m pytest -q` on a CUDA machine.
4. Keep generated data, checkpoints, logs, and experiment outputs outside Git.
5. Report scientific results with seeds, task counts, split definitions, hardware, and uncertainty estimates.

Do not submit third-party data or code unless redistribution is explicitly permitted and attribution is included.
