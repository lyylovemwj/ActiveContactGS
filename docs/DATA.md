# Data and generated artifacts

## Procedural data

The main amortized dataset is generated by `active_contact_gs.generate_amortized_dataset`. Large tensor shards are deterministic and intentionally excluded from Git. The default output location is `data/amortized-v1/`.

The frozen protocol uses:

- 131,072 training tasks;
- 16,384 validation/held-out-ID tasks;
- 16,384 OOD-thin tasks;
- 16,384 OOD-near-round tasks;
- six candidate observations per generated task;
- observation noise standard deviation 0.006.

## YCB subset

`scripts/download_ycb_subset.sh` downloads eight official Google 16k objects: cracker box, mustard bottle, banana, bowl, mug, power drill, hammer, and Rubik's cube. The script records archive and extracted-file SHA-256 checksums.

YCB files are not included in this repository. Review the current official terms before downloading or redistributing them.

## Outputs and checkpoints

All generated artifacts belong under ignored paths:

```text
data/          generated and external datasets
outputs/       checkpoints, JSON/CSV results, logs, plots, and manifests
third_party/   independent upstream repositories
```

For an archival research release, publish checkpoints and result snapshots separately using Git LFS, GitHub Releases, Hugging Face, or Zenodo. Never commit private credentials, server addresses, reviewer material, or licensed external datasets.
